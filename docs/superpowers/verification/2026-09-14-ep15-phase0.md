## 1. Tick endpoint — SPY, 2026-09-11 14:00:00–14:59:59 UTC (HTTP 200, 97,310 prints)

| Assumption | Live result |
|---|---|
| payload is a list of record dicts | **WRONG — columnar**: one dict of equal-length arrays `{ts, price, shares, seq, sl, mkt, sub_mkt}` |
| fields ts/price/shares/seq/sl/mkt/sub_mkt/ex | all present **except `ex`** (not sent); nothing reads it |
| ts in ms UTC | yes; every print inside the requested window |
| seq unique within session | yes: 0 repeated seq, 0 (ts, seq) dupes, seq non-decreasing with ts |
| sl is 4 chars | yes, all 97,310 |

**Fixed:** `parse_tick_payload` zips a columnar dict into records (list input still accepted);
`capture.row_count_hint` counts `len(ts)` for columnar payloads (was `None` for every live tick
capture). Without the parser fix every live `fetch_week` failed — the CI suites only ever fed the
list-shaped fixture. Re-parsing the live capture after the fix: 97,310 rows, trade_date 2026-09-11.

## 4. Membership boundary evidence — **decision needed**

S&P DJI press release (2026-09-04): Bloom Energy (BE), Illumina (ILMN) and Everpure (P) replace
Molson Coors (TAP), The Trade Desk (TTD) and Builders FirstSource (BLDR) "prior to the open of
trading on Monday, September 21, 2026".

EODHD, observed 2026-09-14: ILMN/BE/PSTG `StartDate` = 2026-09-21 **and** TTD/BLDR/TAP
`EndDate` = 2026-09-21. The same pattern holds for earlier swaps: EA ends 2026-08-05 when FERG
starts; AVB ends 2026-08-18 when RDDT starts; POOL and CPB end 2026-06-22 when FLEX and MRVL start.

- `StartDate` = first member session — matches `MEMBERSHIP_BOUNDARY_V1`.
- `EndDate` = the removal's **effective date, i.e. the first NON-member session** — exclusive.
  V1 documents `membership_effective_to` as the last member session (inclusive) and passes the
  vendor date through unchanged, so every swap day currently resolves both the outgoing and the
  incoming name as members. PIT constituent count from this capture:

  | date | end-inclusive (V1 as documented) | end-exclusive |
  |---|---|---|
  | 2026-06-22 | 505 | 503 |
  | 2026-08-05 | 504 | 503 |
  | 2026-08-18 | 504 | 503 |
  | 2026-09-18 (no change) | 503 | 503 |
  | 2026-09-21 | 506 | 503 |

  End-exclusive holds at exactly 503 on every swap day.
- Not amended here: fixing it is either a `MEMBERSHIP_BOUNDARY_V2` that shifts `effective_to` to
  the prior session, or re-documenting V1 as end-exclusive and flipping the PIT predicate. Both
  change stored semantics — Art's call.

Vendor identity lag: S&P lists Everpure as ticker **P**; EODHD's components still show
`PSTG` / "Pure Storage Inc". The symbol-change path must bridge that rename before 2026-09-21
or the new member resolves to the old code.
