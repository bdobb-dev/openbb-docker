## 1. Tick endpoint — SPY, 2026-09-11 14:00:00–14:59:59 UTC (HTTP 200, 97,310 prints)

| Assumption | Live result |
|---|---|
| payload is a list of record dicts | **WRONG — columnar**: one dict of equal-length arrays `{ts, price, shares, seq, sl, mkt, sub_mkt}` |
| fields ts/price/shares/seq/sl/mkt/sub_mkt/ex | all present **except `ex`** (not sent); nothing reads it |
| ts in ms UTC | yes; every print inside the requested window |
| seq unique within session | yes: 0 repeated seq, 0 (ts, seq) dupes, seq non-decreasing with ts |
| sl is 4 chars | yes, all 97,310 |

**Fixed:** `parse_tick_payload` zips a columnar dict into records (list input still accepted);
`capture.row_count_hint` counts `len(ts)` for columnar payloads (was `None` for every live tick
capture). Without the parser fix every live `fetch_week` failed — the CI suites only ever fed the
list-shaped fixture. Re-parsing the live capture after the fix: 97,310 rows, trade_date 2026-09-11.

## 4. Membership boundary evidence — resolved: end-exclusive (V2)

S&P DJI press release (2026-09-04): Bloom Energy (BE), Illumina (ILMN) and Everpure (P) replace
Molson Coors (TAP), The Trade Desk (TTD) and Builders FirstSource (BLDR) "prior to the open of
trading on Monday, September 21, 2026".

EODHD, observed 2026-09-14: ILMN/BE/PSTG `StartDate` = 2026-09-21 **and** TTD/BLDR/TAP
`EndDate` = 2026-09-21. The same pattern holds for earlier swaps: EA ends 2026-08-05 when FERG
starts; AVB ends 2026-08-18 when RDDT starts; POOL and CPB end 2026-06-22 when FLEX and MRVL start.

- `StartDate` = first member session — matches `MEMBERSHIP_BOUNDARY_V2`.
- `EndDate` = the removal's **effective date, i.e. the first NON-member session** — exclusive.
  V1 documented `membership_effective_to` as the last member session (inclusive); read that
  way, every swap day counts both the outgoing and the incoming name. PIT constituent count
  from this capture:

  | date | end-inclusive (V1 as documented) | end-exclusive |
  |---|---|---|
  | 2026-06-22 | 505 | 503 |
  | 2026-08-05 | 504 | 503 |
  | 2026-08-18 | 504 | 503 |
  | 2026-09-18 (no change) | 503 | 503 |
  | 2026-09-21 | 506 | 503 |

  End-exclusive holds at exactly 503 on every swap day.
- **Resolved (Art, 2026-09-14): end-exclusive, `MEMBERSHIP_BOUNDARY_V2`.** Vendor dates are
  stored unchanged. `reference_queries`' PIT SQL was already end-exclusive
  (`membership_effective_to > market_date`); the inclusive reading lived in the V1 docs,
  membership's same-listing overlap check, and the manifest's week overlap (a Monday removal got
  one extra week of fetches). Both overlaps are now half-open. No V1 rows existed: nothing in
  production called `build_membership` until the reference-sync wiring below.

Vendor identity lag: S&P lists Everpure as ticker **P**; EODHD's components still show
`PSTG` / "Pure Storage Inc". The symbol-change path must bridge that rename before 2026-09-21
or the new member resolves to the old code.

## 6. Step 2 — reference sync + manifest (live, 2026-09-14)

`vault reference --sync`: 822 constituents → 818 RESOLVED, 0 AMBIGUOUS, 4 UNRESOLVED
(`CAM_old`, `IILGV`, `LEN-N` placeholder security, `MRP_old`); 503 open-ended members (= the
index today); fundamentals attached for 821 of 822. ~8,250 EODHD credits, 19 min.

`vault manifest --generate 2016-09-12 2026-09-07`: 250,237 PENDING rows over 522 weeks, 0
BLOCKED_IDENTITY, 419–503 names per week (median 489); 2026-08-31 has 501 rows, the same
universe the legacy loader used for that week. 5.3 min.

Bugs found running it (fixed, CI green):
- `c6aa4c2` — `engine._to_date` passed CLI ISO strings through, so `manifest --generate` crashed;
  `vault status` always printed 0 open DQ issues (no reader wired); it now reads the table (145).
- `0db2c80` — reconcile's flag helpers truth-tested `sale_condition_flags`, which Delta returns as
  a numpy array: the calibration crashed on its first symbol. Unit suites only fed Python lists.

- Calibration timeout crash: a socket read `TimeoutError` escapes urllib unwrapped, and
  `UrlLibTransport` retried only `URLError`; `fetch_week` also used a 30 s per-call timeout against
  sip_backfill's proven 1800 s. The transport now retries any `OSError`, the tick timeout is 1800 s,
  and a spent-retries `OSError` is treated like a 5xx (halve the window / fail it) instead of
  crashing the run.

**Start-unknown membership — resolved (Art, 2026-09-14): floor.** 145 constituents carry no
EODHD `StartDate`. Bounding their start at the capture date (2026-09-14) inverted 143 ex-member
intervals (from > to) — 73 of them left the index inside the backfill span (e.g. AET, CELG, BCR)
and vanished from the manifest; IR and WAB lost all pre-2026 history. Now
`membership_effective_from` is floored at `MEMBERSHIP_START_FLOOR` = 1957-03-04 (the index's
inception; EODHD dates CPB's join to it), tagged `START_DATE_UNKNOWN_FLOORED` with the same
WARN DQ row. Accepted cost: these rows over-fetch weeks before their real (unknown) join and
widen PIT membership for them.
