## Pre-flight rulings

Ruling: T7's two tests that name `pivots_standard` move to T8; T7 tests the mechanism against a throwaway indicator registered inside the test module — because the plan as written has T7 commit with two failing tests, which breaks the red/green discipline every other task follows and hands the reviewer a broken suite. Cost if wrong: T7's mechanism test is slightly less realistic than one using the real indicator.

Ruling: `series_delta` computes every series' times from the FULL frame and then slices `data` by index, rather than running `shift_times` over the slice — because a one-row slice has no spacing to infer, so `shift_times` returns `[None]` and a displaced series' delta loses its timestamps entirely. The plan's comment claiming the slice's own spacing suffices is wrong and is removed. Cost if wrong: none identified; this is strictly more correct.

Ruling: `st_direction` is NOT listed in supertrend's `render` — because a width-0 line is a rendering hack that would still ship an invisible series to the lightweight-charts client, and direction is internal state, not a plotted study. The column is still computed and still addressable in tests via `col("supertrend", "st_direction")`. Cost if wrong: a later feature wanting to colour the line by direction must add it to `render` then.

Ruling: the ADJ control keeps its approved scope via a new `basis` param (adjusted|raw) threaded through `ChartParams` into `bars_to_frame`, which sets `adj_close = close` when basis is raw — because `price_basis` is fixed per indicator in the registry and a genuine per-request override would mean rewriting `price_col` at 13 indicators' two call sites each, which no task in either plan scoped. `bars_to_frame` already computes `adj_close` in exactly one place, so this is one branch. The manifest's `source` param keeps its honest local|eodhd meaning. Cost if wrong: `basis=raw` makes adjusted-basis indicators read raw close for every symbol, which is precisely the intent, but it is a frame-level switch and could not express a per-indicator mix if one were ever wanted.

Ruling: T1's "Produces" note says Task 11 lists hma and trix in the manifest description; T11's description names ichimoku and supertrend instead. Illustrative text, no action. Cost if wrong: none.

Ruling: `session_columns` does NOT sort the frame internally — it documents that the frame is ascending by date, as every other path in the engine already assumes (parabolic_sar walks it in order too). Because the lists it returns are assigned onto the caller's frame by row position, sorting inside would reorder them relative to those rows and silently mis-assign every value; `group_by_dynamic` requires the same ordering and raises without it. Cost if wrong: an unsorted frame raises from group_by_dynamic instead of being tolerated — which is the correct failure, not a silent wrong answer.

Plan file amended in the worktree for all six rulings (commit below). Task briefs are extracted from the amended plan, so implementers see the rulings as requirements rather than as context.
